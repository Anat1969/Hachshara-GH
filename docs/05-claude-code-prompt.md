עקרונות:
- עברית ו-RTL בכל הממשק. ללא אייקונים.
- לעבוד לפי סקיל end-to-end-builder. חריגה ממנו נאמרת מראש.
- לא לעצור לשאלות שאפשר להכריע לבד. להחליט ולציין הנחה בשורה אחת.
- אם מסמך סותר את מסמך אחר, לפעול לפי docs/04-mvp-scope.md.

סדר עבודה:
1. Vite + React. Supabase לנתונים ולכניסה עם Google. בדיקה מוקדמת של /auth/v1/settings.
2. יצירת סכמה לפי docs/03-data-model.md, כולל RLS ומצבי הרשאה לפי התפקיד. מיגרציה דרך Supabase.
3. זרימות מסלול 1 עד 5 לפי docs/02-user-flows.md, כולל כל מצבי המערכת.
4. סרגל ניווט עליון קבוע, שם המערכת כקישור לדף הבית, כפתורי "העתקת קישור" ו"שיחת הפיתוח", ואפשרות התקנה מ-Chrome.
5. נתוני שבעת השלבים והתוצרים נכנסים כ-seed, לפי docs/04-mvp-scope.md.
6. בדיקה: Playwright מול vite preview עם מוקים ל-Supabase. ללחוץ על כל כפתור ולוודא את הבקשה שנשלחת. לבדוק בנייד בלי גלילה אופקית.
7. קומיט ודחיפה ל-main. אחרי בדיקה ירוקה, מיזוג ל-main בלי לשאול.
8. Vercel: יצירת פרויקט בשם CULTURA-GH מתוך הריפו, ללא teamId, ללא הגנת SSO, ענף ייצור main.
9. עדכון CLAUDE.md בריפו עם כל תיקון שהתקבל מהמשתמשת.

מסירה: כתובת סופית ושורה אחת על מה השתנה. לא להעביר צעדים, מפתחות או סיסמאות.
