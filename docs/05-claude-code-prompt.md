עקרונות:
- עברית ו-RTL בכל הממשק. ללא אייקונים בממשק.
- סרגל ניווט עליון קבוע בכל הדפים. שם המערכת קישור לבית. כפתור לוגו A&I יחיד בצד שמאל עם כל הפעולות (עריכה, פיתוח, הקנייה).
- כניסה חופשית: קריאה ציבורית, כתיבה דרך פונקציות cgh_ (SQL), משתתף מזוהה בתו עריכה פרטי (?k=).
- לעבוד לפי סקיל anat-app-builder ו-anat-standards. חריגה ממהם נאמרת מראש.
- לא לעצור לשאלות שאפשר להכריע לבד. להחליט ולציין הנחה בשורה אחת.
